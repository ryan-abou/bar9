# Monthly emails

Kit's free plan doesn't turn new posts into emails automatically, so each issue
gets an email version here, and Ryan pastes it into Kit and sends it.

## When

On the first Sunday of the month, right after the issue is published (status
`published` and pushed, so the link works).

## In Kit

1. Broadcasts → New broadcast.
2. Subject and preview text: copy from the issue's file in this folder.
3. Body: paste the email text. Add the link to the issue on the "Read it on the
   site" line.
4. Send a test to yourself first (Kit's "Send test" button), check it on your phone.
5. Send to all subscribers.

## How the email differs from the page

- Margin notes don't work in email. Fold the useful ones into the text or drop them.
- No images except the issue's one photo, if it has one.
- Start with one or two lines from Ryan, then the story, then the PianoGlass part.
- End with the link to the issue on the site (sources live there).
- Same voice rules as the blog (see ../CLAUDE.md).

## Files

One file per issue: `YYYY-MM-noN.md` with the subject, preview text and body.
